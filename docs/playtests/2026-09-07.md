## What broke

**Elimination read as arbitrary, and the cause was a missing display rather than a missing rule.**
The three-second grace period was working exactly as configured. `ZoneEliminationSystem` counts a
blob's consecutive ticks outside the zone and eliminates it when the count passes
`elimination_grace_ticks`, and the server was already publishing that count as the `zone_exposure`
component on every frame. The client received it and threw it away: the renderer registry marked
`zone_exposure` non-visual with a note that it belonged in the HUD, and the HUD row was never added.
So a player bumped out saw nothing happen, waited, and concluded the rule was broken.

Fixed on the same day: an exposed blob now draws a warning ring, the local player's is heavier and
red, and the HUD shows the exposure while it lasts. The client still cannot show a countdown,
because the grace duration is mode configuration and no schema carries it to the client; the plan
step that puts it on the wire is written and sequenced behind the hazard work.
