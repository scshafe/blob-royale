readiness request omitted `X-Forwarded-For`; loopback is a trusted-proxy peer in this deployment, so the server correctly
answered `400` with `forwarded_client_absent`. After ten seconds the script reported
`DEPLOY.NOT_READY` and exited `1`. Independent tailnet readiness was `200`, and adding
`X-Forwarded-For: 127.0.0.1` to the local probe also produced `200`; omitting it reproduced the `400`.
Those `c5baef0` running-image checks and live smokes did not establish a successful deployment
command. Plan Step 20c's probe correction passed shell syntax and all 149 focused server/fixture

four native builds, 1,135 tests on each of GCC Debug, combined Clang ASan/UBSan, and Clang TSan,
plus web, browser, fuzz regression,
and dependency security. The corrected `b1e80d4` canonical native deployment subsequently passed
with exit `0`; its separate current-release evidence is recorded above. This resolves the probe
